# hall_booking — منصة حجز القاعات

منصة إلكترونية لإدارة القاعات: إرسال الحجوزات، إدارة مواعيدها، إدارة القاعات ومحتوياتها، ومتابعة أعمال الصيانة.

## البدء السريع
1. ثبّت **Node.js 20 أو أحدث** من https://nodejs.org (مرة واحدة).
2. شغّل **`control app.bat`** واختر **[1] تنصيب كامل**.
3. اختر **[4]** للتشغيل المؤقت أو **[7]** للتشغيل الدائم كخدمة ويندوز.
4. افتح **http://localhost:5050**

## الأدلة
- `docs\INSTALL.md` — دليل التنصيب والتشغيل والتحديث والنسخ الاحتياطي
- `docs\USER_GUIDE.md` — دليل المستخدم لكل الأدوار
- `docs\REVIEW_REPORT.md` — تقرير المراجعة الشاملة وما تمت معالجته

> المجلدات `data` و `backups` و `logs` والملف `config.env` تُنشأ تلقائياً وتحتوي بيانات المنظومة — لا تحذفها عند التحديث.

## البيانات الأولية
ملف `source_code/database/initial-data.sql` (بيانات الجهة: المستخدمون، القاعات، الإعدادات) **غير مرفوع إلى المستودع** لأنه يحتوي بيانات حسابات.
- عند وجوده في المجلد يُستورد تلقائياً في أول تشغيل.
- عند عدم وجوده تُنشأ منصة فارغة بحساب `admin` وكلمة مرور مؤقتة تُكتب في `data\INITIAL_ADMIN_PASSWORD.txt`.
